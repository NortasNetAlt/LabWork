# LabWorks
### Lab4DZ
### Домашняя работа (Условие задачи)
Доставка грузов
Три груза (A, B, C кг) можно погрузить в контейнер, если вес каждого из них кратен пяти. Запишите условие, при котором диспетчерская система дает разрешение на погрузку.
### Ход решения
**1. Ход решения**
1. Объявить три переменные (A, B, C) для хранения веса грузов.
2. Ввести значения A, B и C с клавиатуры.
3. Сделать проверку, делится ли вес каждого груза на 5 без остатка.
4. Условие разрешения на погрузку груза:
(A % 5 == 0) && (B % 5 == 0) && (C % 5 == 0)
Если условие истинно, результат равен 1. Следовательно, погрузка разрешена
Если хотя бы один груз не делится на пять, результат равен 0. Следовательно, погрузка запрещена.
