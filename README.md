# Домашняя работа (Условие)
**Задача:**

Вычислить с использованием цикла `for` значение ряда для заданных пользователем значений `a` и `n` (Вариант 3. Ряд с факториалами в знаменателе):
1/a + 1/(a(a+1)) + ... + 1/(a(a+1)...(a+n))

**Дано:**
Пользователь вводит значения `a` и `n` с клавиатуры. 
Знак члена ряда определяется автоматически через множитель (в данном случае все члены положительные).

**Контрольные примеры:**
*   Пример 1: `a = 2, n = 2` -> Результат: `0.708333`
*   Пример 2: `a = 1, n = 4` -> Результат: `1.716667`

# Алгоритм и блок-схема

### 1. Алгоритм

1. Объявить вещественные переменные `a` (основание), `sum` (сумма ряда), `denom` (текущий знаменатель) и целочисленную переменную `n` (количество шагов).
2. Вывести на экран приглашение к вводу значений.
3. Считать значения `a` и `n`.
4. Инициализировать `sum = 0.0` и `denom = 1.0`.
5. Запустить цикл с параметром `for` (от `i = 0` до `n` включительно):
   - Внутри цикла накапливать знаменатель: `denom = denom * (a + i)`.
   - Добавлять очередной член ряда к сумме: `sum = sum + 1.0 / denom`.
6. Вывести на экран вычисленное значение `sum`.
7. Завершить работу программы.

# 2. Реализация программы

Программа реализована на языке С.

Для ввода значений используется функция `scanf()`.

**Вычисление суммы ряда реализовано через цикл `for`:**
*   `for (int i = 0; i <= n; i++)` — цикл с параметром, выполняющийся `n + 1` раз (от 0 до n).
*   `denom *= (a + i)` — накапливает знаменатель `a * (a+1) * ... * (a+i)`.
*   `sum += 1.0 / denom` — вычисляет текущий член ряда и прибавляет его к общей сумме.

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>


int main() {
    setlocale(LC_CTYPE, "RUS");
    taskhome();
    return 0;
}

int taskhome() {
    // Вариант 3. Ряд с факториалами в знаменателе
    //Контрольный пример a = 2 n = 2
    //Результат: 0.708333
    //Контрольный пример a = 1 n = 4
    //Результат: 1.716667
    double a;
    int n;
    double sum = 0.0;
    double denom = 1.0;
    puts("Введите a и n:");
    scanf("%lf %d", &a, &n);
    for (int i = 0; i <= n; i++) {
        denom *= (a + i);       // накапливаем знаменатель a*(a+1)*...*(a+i)
        sum += 1.0 / denom;     // прибавляем очередной член ряда
    }

    printf("Результат: %lf\n", sum);

    return 0;
}
```
