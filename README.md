# Домашняя работа (Условие)
**Задача:** Определить, принадлежит ли точка с координатами \((x, y)\) заштрихованной области на плоскости.
Область задана следующими условиями:
1. Точка находится справа от оси Y: x >= 0
2. Точка находится ниже прямой y = -x: y<=-x
3. Точка находится внутри окружности радиусом корень из 2: x^2 + y^2 <=2

**Дано:**
Пользователь вводит координаты x и y с клавиатуры.

**Контрольные примеры:**
*   Внутри: (0.5, -0.5) -> принадлежит
*   Снаружи: (1.5, -1.5) -> не принадлежит
*   Слева: (-1, -1) -> не принадлежит

# Алгоритм и блок-схема
### 1. Алгоритм

1. Объявить вещественные переменные x, y для хранения координат точки.
2. Вывести на экран приглашение к вводу координат.
3. Считать значения x и y с клавиатуры.
4. Проверить выполнение трех условий одновременно (через логическое И &&):
   - Первое условие: x >= 0 (точка не левее оси Y).
   - Второе условие: y <= -x (точка ниже или на прямой y = -x.
   - Третье условие: (x * x + y * y) <= 2 (точка внутри или на границе окружности).
5. Если все три условия истинны, вывести сообщение, что точка принадлежит области.
6. Иначе вывести сообщение, что точка не принадлежит области.
7. Завершить работу программы.

# 2. Реализация программы

Программа реализована на языке С.

```c
#include <stdio.h>

int taskhome() {
    double x, y;
    printf("Введите координаты точки (x y): ");
    scanf("%lf %lf", &x, &y);

    // Контрольный пример:
    // Внутри: (0.5, -0.5) -> принадлежит
    // Снаружи: (1.5, -1.5) -> не принадлежит
    // Слева: (-1, -1) -> не принадлежит

    if (x >= 0 && y <= -x && (x * x + y * y) <= 2) {
        printf("Точка (%.2lf, %.2lf) Принадлежит заштрихованной области\n", x, y);
    } else {
        printf("Точка (%.2lf, %.2lf) Не принадлежит заштрихованной области\n", x, y);
    }
    return 0;
}

int main() {
    taskhome();
    return 0;
}
```

**Пояснения к условию `if`:**
*   `x >= 0` — проверяет, что точка находится в правой полуплоскости.
*   `y <= -x` — проверяет, что точка находится под прямой \(y = -x\).
*   `(x * x + y * y) <= 2` — проверяет, что расстояние от начала координат до точки не превышает радиус окружности \(\sqrt{2}\) (так как \(x^2 + y^2 = R^2\), а \(R^2 = 2\)).
*   `&&` — логическое "И", требует выполнения всех трех условий одновременно.
